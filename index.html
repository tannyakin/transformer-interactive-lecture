§1 · the core problem

Why attention?

A recurrent network (RNN) reads left to right, one token per step, each step waiting on the last. That makes training slow and lets information from early words fade by the time later words arrive. Attention compares every pair of words in a single pass, with no waiting and no fading. That's the whole idea behind the paper's title: once you have attention, you don't need recurrence at all.

§2 · the mechanism

Anatomy of attention

Every word gets turned into three short vectors. Click any word below to make it the query and watch it re-weight every other word in the sentence.

Query, key, value: in plain terms

Think of it like a quick library search.

Query (Q)
what this word is looking for
Key (K)
what each word offers, like a label on a book spine
Value (V)
the actual content that word carries

The query is compared against every key. Close matches score high, poor matches score low, and softmax turns those scores into weights that add up to 1. The word's new representation is a blend of everyone's values, weighted toward whoever it matched best.

§5 · putting order back in

Positional encoding

Attention on its own treats a sentence like a bag of words. Nothing tells it "the" came before "animal." So a fixed wave pattern is added to every token's embedding, one wave per pair of dimensions, each at a different frequency. The sliders below control one of those waves. The row of tokens underneath lets you compare any two positions directly and see exactly how similar their full encodings are.

Low i (early dimensions) oscillates fast, changing with every position. High i oscillates slowly, changing only over long stretches. Together they give every position a unique fingerprint.

§6 · reference

Key equations

scaled dot-product attention
Attention(Q,K,V) =
  softmax( QKᵀ / √d_k ) V
Score every value by how well its key matches the query, turn scores into weights with softmax, then blend the values. Dividing by √d_k keeps scores from growing too large as vectors get longer.
multi-head attention
head_i = Attention(QWᵢQ, KWᵢK, VWᵢV)
MultiHead = Concat(head₁,…,headℎ) Wᴴ
Run the comparison h separate times, each on its own learned slice of Q, K, V, so different heads catch different relationships. Glue the results together and mix with one more linear layer.
position-wise feed forward
FFN(x) = max(0, xW₁+b₁) W₂+b₂
Two small dense layers with a ReLU between them, applied separately to each token. It never lets tokens compare notes. That is attention's job.
positional encoding
PE(pos,2i) = sin( pos / 10000^(2i/d_model) )
PE(pos,2i+1) = cos( pos / 10000^(2i/d_model) )
A fixed wave added to each token's embedding so the model can tell position 1 apart from position 5. See the visualizer above.

§7 · vocabulary

Terms to know

A quick reference for the vocabulary used throughout. Start typing to filter.

Token
A piece of text the model treats as one unit, often a word or part of a word. "Unbelievable" might split into "un", "believ", and "able".
Embedding
A vector representing a token's meaning, learned during training so similar tokens end up with similar embeddings.
Vocabulary
The fixed list of every token the model knows, often tens of thousands of entries.
d_model
The length of the vector used to represent every token as it moves through the network: 512 in the base model, 1024 in the big one.
Parameter
A single learned number inside the model. Model size is usually measured by how many parameters it has.
Logits
The raw, unnormalized scores the model outputs for each vocabulary token, right before softmax.
Softmax
Turns a list of scores into probabilities that sum to 1, so the largest scores dominate but nothing drops to exactly zero.
Layer normalization
Rescales each token's vector to keep values in a stable range, helping deep networks train reliably.
Residual connection
A shortcut adding a sublayer's input back onto its output, so information can skip past that sublayer.
Feed-forward network (FFN)
Two stacked dense layers with a nonlinearity between them, applied identically to every token position.
Self-attention
Attention where queries, keys, and values all come from the same sequence.
Cross-attention
Attention where queries come from one sequence (the decoder) and keys/values come from another (the encoder).
Causal mask
Hides future positions from a query, so a word can only attend to itself and whatever came before it.
Dropout
Randomly zeroing some values during training so the model can't over-rely on any single connection.
Label smoothing
Training the model to aim for, say, 90% confidence instead of 100%, keeping it from getting overconfident.
