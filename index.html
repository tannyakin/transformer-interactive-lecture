    The Transformer

    Before 2017, language models read a sentence one word at a time, carrying a summary forward and slowly forgetting the beginning by the time they reached the end. The Transformer throws that away: every word looks directly at every other word, all at once. This lecture takes that idea apart piece by piece, and in Part 4 you will do the attention arithmetic yourself.

    Part 1: Why attention

    Recurrent networks read one word at a time. What do we gain by letting every word look at every other word at once?

    A recurrent network (RNN) reads left to right, one token per step, and each step has to wait for the one before it. That makes training slow, and it lets information from early words fade by the time later words arrive.

    Attention compares every pair of words in a single pass, with no waiting and no fading. That is the whole idea behind the paper's title: once you have attention, you do not need recurrence at all.

    So attention compares every pair of words in one step. The next question is what exactly gets compared, and how a word decides who matters.

    Part 2: Anatomy of attention

    When a word looks at the rest of the sentence, how does it decide who matters?

    Every word gets turned into three short vectors. Think of it like a quick library search:

    Query (Q)
    what this word is looking for
    Key (K)
    what each word offers, like the label on a book's spine
    Value (V)
    the actual content that word carries

    The query is compared against every key. Close matches score high, poor matches score low, and softmax turns those scores into weights that add up to 1. The word's new representation is a blend of everyone's values, weighted towards whoever it matched best.

    One word, three vectors, one weighted blend. Now zoom out: where does this step sit inside the whole model?

    Part 3: The encoder-decoder stack

    How do the pieces fit together to turn one sentence into another?

    The encoder reads the input and builds a representation of it. The decoder writes the output one token at a time, attending both to what it has written so far and to the encoder's representation. One layer of each is drawn below. The base model stacks N = 6 of each.

    Three of those boxes are attention: self-attention, masked self-attention and cross-attention. They all run the same small computation. Time to open one up and do it by hand.

    Part 4: Inside attention

    What actually happens inside an attention box, number by number?

    Every attention box in the diagram runs the same short recipe, called scaled dot-product attention: compare, scale, optionally mask, softmax, blend. Below it is worked through with numbers small enough to check with a pencil. The diagram beside the numbers lights up the box you are in.

    Attention(Q, K, V) = softmax( QKT / √d_k ) V

    Multi-head: the same recipe, h times

    "Multi-head" just means running that recipe several times in parallel, each time on a different learned slice of the vectors, then gluing the results back together. Change the number of heads and step through the stages.

    Where the mask lives

    The mask only exists in the decoder's first attention layer. It blocks each position from looking at positions after it, which is what keeps generation strictly left to right.

    There is one thing the computation you just did never looks at: where each word sits in the sentence. Positional encoding is the patch that puts that information back.

    Part 5: Positional encoding

    Attention treats a sentence like a bag of words. How does the model know which word came first?

    Nothing in attention tells it that "the" came before "animal". So the original paper adds a fixed wave pattern to every token's embedding: one wave per pair of dimensions, each at a different frequency.

    The sliders below control one of those waves. The row of positions underneath lets you compare any two positions directly and see how similar their full encodings are.

    That is every moving part of the model. The next part collects the four equations behind them in one place.

    Part 6: Key equations

    Can you read the whole model in four short lines of maths?

    Scaled dot-product attention

    Attention(Q, K, V) = softmax( QKT / √d_k ) V

    Score every value by how well its key matches the query, turn the scores into weights with softmax, then blend the values. Dividing by √d_k stops the scores growing too large as vectors get longer.

    Multi-head attention

    head_i = Attention(QW_iQ, KW_iK, VW_iV) MultiHead = Concat(head_1, …, head_h) WO

    Run the comparison h separate times, each on its own learned slice of Q, K and V, so different heads can catch different relationships. Glue the results together and mix them with one more linear layer.

    Position-wise feed forward

    FFN(x) = max(0, xW_1 + b_1) W_2 + b_2

    Two small dense layers with a ReLU between them, applied to each token on its own. Tokens never compare notes here. That is attention's job.

    Positional encoding

    PE(pos, 2i) = sin( pos / 10000^(2i/d_model) ) PE(pos, 2i+1) = cos( pos / 10000^(2i/d_model) )

    A fixed wave added to each token's embedding so the model can tell position 1 from position 5. This is the wave you played with in Part 5.

    Part 7: Terms to know

    What does each piece of transformer vocabulary actually mean?

    Token
    A piece of text the model treats as one unit, often a word or part of a word. "Unbelievable" might split into "un", "believ" and "able".
    Embedding
    A vector that represents a token's meaning, learned during training so that similar tokens end up with similar embeddings.
    Vocabulary
    The fixed list of every token the model knows, often tens of thousands of entries.
    d_model
    The length of the vector that represents each token as it moves through the network: 512 in the base model, 1024 in the big one.
    Parameter
    A single learned number inside the model. Model size is usually measured by how many parameters it has.
    Logits
    The raw scores the model outputs for each vocabulary token, right before softmax.
    Softmax
    Turns a list of scores into probabilities that add up to 1, so the largest scores dominate but nothing drops to exactly zero.
    Layer normalisation
    Rescales each token's vector to keep its values in a stable range, which helps deep networks train reliably.
    Residual connection
    A shortcut that adds a sublayer's input back onto its output, so information can skip past that sublayer.
    Feed-forward network (FFN)
    Two stacked dense layers with a nonlinearity between them, applied in the same way to every token position.
    Self-attention
    Attention where the queries, keys and values all come from the same sequence.
    Cross-attention
    Attention where the queries come from one sequence (the decoder) and the keys and values come from another (the encoder).
    Causal mask
    Hides future positions from a query, so a word can only attend to itself and whatever came before it.
    Dropout
    Randomly zeroing some values during training so the model cannot lean too hard on any single connection.
    Label smoothing
    Training the model to aim for, say, 90% confidence instead of 100%, which keeps it from becoming overconfident.
